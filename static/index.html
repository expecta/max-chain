How difficulty works

Every few blocks, Max checks how fast blocks were made. Way too fast (less than half the target time)? The puzzle gets one zero harder. Way too slow (more than double)? One zero easier. These rules are saved in the very first block, and the validator checks every block follows them, so nobody can cheat.

Rules for a new chain can be changed with MAX_TARGET, MAX_RETARGET and MAX_DIFFICULTY before the first start.
